- 2026-05 Rubin 传闻涉及 HBM4 速度与 base die 质量、良率、翘曲、多电源设计、均热片改版 **[待核实]**；2026-07 Kyber 中板 PCB（448G SerDes）可制造性问题推迟 NVL144。
- 系统级测试中的**静默数据错误（SDC）**：Meta 报告约每千颗加速器 1 颗；字节跳动 OSDI'26 研究了生产中发现的 23 颗 SDC GPU。→ 对应 **SLT 失效（死机 / SDC）**。

## 3. 工艺流程与典型失效模式（演示知识库的依据）

| 工段 | 失效模式 → 常见根因 | 典型指标 |
|---|---|---|
| 光刻（EUV / DUV 多重图形） | 套刻偏移 ← 镜头/光罩热效应、机台匹配、对准标记受 CMP 损伤；EUV 随机缺陷 | 片上套刻 ≤2–3 nm |
| 刻蚀 | CD 偏移、边缘良率损失 ← 腔体 seasoning、**聚焦环/边缘环随 RF 小时磨损** | 径向边缘良率 |
| 薄膜 CVD/ALD/PVD | PM 前腔壁剥落颗粒；W/Co 填充缝隙；阻挡层台阶覆盖 | 非均匀性 <1–2% |
| CMP | 微划痕 ← 研磨液团聚、垫/修整盘碎屑；碟陷/侵蚀 | 划痕数 |
| 湿法 / 传送 | 水痕、颗粒回沾、金属污染、图形坍塌；机械手划伤 | 金属 ≥1e10 at/cm² |
| CP | 探针卡磨损/污染 → site 间差异 | site 差 >2%，复测恢复率 |
| 2.5D 中介层（CoWoS 类） | 翘曲（CTE）→ C4 非润湿/桥接、底填分层 | 85 mm 载体翘曲 −198～−250 µm（ECTC 2023） |
| HBM TSV 堆叠 | TSV 空洞、薄 die 开裂/翘曲、MR-MUF/NCF 空洞、base die 缺陷 | KGSD 良率 |
| FT | Vmin/Fmax 分档漂移、HBM PHY 训练失败、测试座磨损误判 | FPY、复测率 |
| 老化 | 早期失效（栅氧、金属空洞）、NBTI 漂移、老化座故障 | BI 失效率、ELFR DPPM |
| SLT | 特定负载失效、SDC、NVLink 链路失效 | 约 1/1000 SDC（Meta） |
| 板卡/整机柜 | BGA 枕头效应、背板针弯、快接头/分歧管泄漏、冷板 TIM 空洞 | L10/L11 良率、泄漏率 |

泊松估算：8 cm² 的光罩尺寸 die 在 D0=0.1/cm² 时原始良率约 e^(−0.8)≈45%，这就是大芯片必须做冗余与降级的原因。

## 4. 晶圆厂里真实的 RCA 怎么做（本系统统计内核的依据）

1. **发现**：SPC（Western Electric / Nelson 规则、Cpk）；EAP 经 SECS/GEM、Interface A 采集 FDC，触发 OCAP，在 MES 中 hold 批次或封锁腔体；KLA 光学检测、电子束复检、ADC。
2. **围堵**：以最后良品/首个坏品批次划界（bracketing），从批次履历拉出风险批次。
3. **共性分析**：对机台、腔体、配方、光罩、探针卡、时间做 ANOVA/卡方 → 本系统用 Fisher 精确检验 + Bonferroni。
4. **空间特征（WM-811K 分类）**：中心（RF/气流、CMP 压力）、甜甜圈（去胶残留）、**边缘环（RTP 温度、刻蚀边缘环磨损、去边）**、边缘局部、**划痕（机械手、CMP）**、局部/簇状（颗粒、化学品泄漏）、近满片、随机（基线 D0）。
5. **下钻**：好坏批次 FDC 曲线对比、PCM/WAT 关联、缺陷叠图求 kill ratio、EFA/FIB/TEM 失效分析、分批验证。
6. **CAPA**：PM、经 RMS 改配方、收紧 FDC 限值、更新 FMEA 与控制计划、关 8D。

数据系统：MES、EAP、RMS、FDC、SPC、APC/R2R、RTD；YMS（PDF Exensio、Synopsys Yield Explorer/Odyssey、Onto Discover）；KLA Klarity；STDF；SEMI E142 晶圆图。

**AI / LLM 在良率分析中的公开案例**

- **三星 “Defect Agent”**（2026-11-17 报道）：自研、不用外部模型；缺陷图像视觉 AI + 图像↔晶圆图↔设备履历多模态关联 + 假设推理，数小时缩短到数分钟。
- **SK 海力士**：清州后道产线分阶段部署 AI Agent，测试到 2026 年底。
- **PDF Solutions Exensio**：基于 **MCP** 的 Agent 体系，语义数据层、本地/隔离部署 LLM、可追溯工作流 ID；其 2025-12 演示自称“还不是完整根因分析”。
- **应用材料**：SEMICON Taiwan 2026 展示“推荐 → 人工验证 → 影子模式 → 有限自主”的分阶段良率 Agent，划痕分析 8 小时→12 分钟 **[待核实，仅 LinkedIn 摘要]**。
- **格创东智**：基于 DeepSeek V3/R1 的设备知识库 Agent（2025-03）；含 8D 报告审核的品质 AI Agent（厂商口径）。**智现未来**：AiIM 多模态 Agent Network（厂商口径）。

> 启示：行业领先者都在走“**数据关联 + 假设推理 + 人在回路 + 可追溯**”的路线，而且 MCP 已被 PDF Solutions 等良率软件厂商采用。

## 7. RSIAgent 论文要点（Kaizen RSI 的出发点）

- **论文**：RSIAgent: Autonomous Exploration for Recursive Self-improvement in New Environments，arXiv:2609.15364，2026-09-14。
  作者为 Aether AI、UCSD、UIC。代码：github.com/AetherLabsAI/RSIAgent。中文解读：微信公众号“AI Labor”，2026-10-10。
- **核心思想**：智能体进入陌生环境时，不靠补数据再训练，也不止于管理上下文，而是**自主试错、发现因果关系，并沉淀为可复用记忆**。全程不更新模型参数。
- **三个角色**：
  - 课程 agent：决定探索什么，出前置技能、信息量变体、失败驱动练习和压力测试题，并判断何时停止；
  - 执行 agent：唯一持有可进化记忆的角色，记忆里存环境知识、可复用流程/脚本和教训；
  - 验证 agent：只看环境反馈，与执行 agent 的推理和记忆隔离，返回成功/失败加证据，决定经验能否固化。
- **两阶段探索**：
  - 广度 BRS：名义预算 8 个探索项目，最多 4 个并发，预算在波次之间检查；
  - 深度 DRS：串行、难度递增，每条验证过的经验在出下一题前固化，没有固定预算，由课程 agent 决定停止。
  - 测试时冻结记忆，关闭课程 agent。
- **结果**：底座为开源 GLM-5.3（执行）+ Kimi-K3（课程、验证）。
  - OSWorld 2.0（82 题）：partial 71.97 → 78.98，binary 37.80 → 42.68；
  - Agents' Last Exam（67 题）：partial 83.75 → 84.82，binary 49.25 → 50.75；
  - “超过 GPT-6 Astra”只在 partial 指标上成立：ALE 的 binary 50.75 低于 GPT-6 的 52.24；
  - 官方仓库说明：RSI 列 82 项中只有 41 项是实际运行记录，其余沿用基线分数，且包含挑选过的重试；
  - 消融只有 4 个任务：完整 RSI 74.54%，仅广度 65.52%，仅深度 56.50%（单做深度在部分任务上低于基线）。
- **失败模式**：探索定位不足、验证不完整、记忆固化不可靠，三者互相放大。论文指出有用的记忆必须保留经验的**条件与不确定性**。
- **Kaizen 的落地差异**（如实说明）：
  - 论文的环境是真实软件（OSWorld 等），Kaizen 的环境是晶圆厂数字孪生；
  - Kaizen 的验证 agent 用“干预后指标是否恢复”这一数值反馈做确定性判定，没有用 LLM 判定，原因是论文认为验证是天花板，而数值反馈的规则判定更可靠；
  - 执行 agent 的排序用统计 + 贝叶斯而不是 LLM 策略，所以离线也能运行；
  - 多种子复核后，照搬论文方案在 Kaizen 里只有 +1.6 个百分点（见第 9 节），和论文本身约 +1～5 个百分点的幅度同一量级。所以 v0.4 在它之上做了改进。

## 9. RSI 文献综述与 Kaizen v0.4 的改进依据（2026-11）

用户反馈 v0.3 的 RSI“效果不太好”。我们并行做了三组调研：自我改进 / 自进化智能体文献、学习理论（主动学习、似然学习、经验贝叶斯）、当前最热的智能体核心技术。下面是结论，以及每条结论在 Kaizen 里落到了哪里。

### 9.1 一句话结论

冻结权重的自我改进里，**大的提升不是来自“多记经验笔记”，而是三件事**：
1. 让经验去更新**判断模型本身**；
2. 大量**可验证**的练习；
3. 每次更新都过一道智能体自己无法“刷分”的**验收门**。

RSIAgent 这类“积累文本记忆”的方法，提升普遍只有几个百分点。

### 9.2 主要文献与数据

| 方向 | 工作 | 关键数据 | 对 Kaizen 的启示 |
|---|---|---|---|
| 自我改进 | RSIAgent（2609.15364） | OSWorld binary 37.8 → 42.7；消融仅 4 题 | 方法的出发点；提升幅度本身有限 |

### 9.3 学习理论给出的设计（已实现部分）

- **评估先行**：设参考天花板与半天花板分解，判断瓶颈在先验还是在证据似然；测试集扩到 480 题、10 个种子、配对比较。v0.3 的“+6”复核后只有 +1.6。
- **证据似然**：`log P(c|e) = Σ w_k·log 因子_k − log Z`，w=1 即原排序；岭回归惩罚 λ·Σ(w_k−1)²；牛顿法。学到“共性分析 ×3～5”，修正了专家设定下强证据被先验压住的问题。
- **知识梯度 KG(\*)**：按 Dirichlet-多项分布精确枚举 n = 1/2/4/8 道题后的期望正确率，取每题平均增益的最大值；乘以证据模糊率（弱证据时先验才起作用）。
- **选择偏差**：只在前 3 个假设里找到真因的样本会让权重学偏，校准题允许试 5 个假设，接近“对所有候选都做干预”的无偏标签。
- **模拟到现实**：孪生能可靠迁移的是“证据长什么样”（似然形状），不太能迁移的是“各根因多常见”（先验）和噪声水平。所以在线模式下校准题只学证据权重，不改产线先验，孪生权重也只有 0.5。

### 9.5 还没做、但文献支持的方向（路线图）

1. **测试时推演**：对每个真实案例，在孪生里模拟前几名根因及组合，比较预测特征与观测（RSIAgent 的练习本来就是“针对目标任务”的；TTC-RL 同理）。在当前的模拟评测里这样做会接近作弊（孪生就是生成器），要等孪生用真实数据校准后才有意义。
2. **按期望信息增益和成本选择干预**：故障排查理论中按 p/C 排序整改，并在“多做一个观测”和“直接整改”之间权衡（Heckerman、Breese 等）；指标增加“解决问题的期望成本”。
3. **分层经验贝叶斯先验**：按根因类别（机台漂移、PM 引入、来料、工艺窗口、量测假象）跨症状共享先验，用 Minka 不动点法从产线历史估计先验强度。
4. **类型化规则**：条件、作用对象、正负向、适用范围、证据计数，编译成似然比进入排序（OpsHarness K3）。
5. **用真实数据校准孪生**：ABC / BayesSim 拟合孪生参数，用“真实 vs 孪生”的分类器两样本检验逼真度。
