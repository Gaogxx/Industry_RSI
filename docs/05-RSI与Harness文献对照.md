# RSI 与 Harness 文献对照：Kaizen 的每个做法为什么重要、怎么做

本文把 Kaizen 已有的做法、v0.7 的快脑小模型与 Harness 层，逐条对应到 2016–2026 年的论文与技术报告：文献怎么说、为什么重要、Kaizen 具体怎么做。
数字均取自论文正文或摘要（2026-11 核对）；标注“媒体”的数字只出现在媒体报道里，一手来源没有找到。

## 1. 已有做法的文献依据

### 1.1 验收门：每次更新都要在封存的题上“不退步”

- **文献**
  - OpsHarness：去掉验收门的自进化版本比不进化还差。
  - RSI-Opt 刻意不设验收门，结果在训练任务上一路上涨（+10.48 → +14.33），留出任务却在第 1 代之后不再提升。强模型在留出任务上甚至变差（Opus：+5.22 → +4.87）。
  - RRSI 用“稳定性下限”：候选不能比当前最好低于噪声带。
- **为什么重要**：自进化最常见的失败不是学不会，而是学到噪声、越改越窄。
- **Kaizen 怎么做**
  - 证据权重每次重拟合都过验收门（面板对数损失不变差、首位命中率最多降 1 个点）。
  - v0.6 起，harness 策略晋升要过 search / select / report 三道题集。
  - 可靠度模型晋升要过留出集上的配对 bootstrap 区间。

### 1.2 数字孪生 = 可验证的环境；标签从不来自模型自评

- **文献**
  - 五大路线综述把评估信号按强度排序：形式化验证器最强，模型自评最弱；实际提升的大小也按这个顺序排列。
  - R-Zero 用多数投票做伪标签，伪标签准确率从 79% 掉到 63%，几轮后崩溃。
  - Self-Rewarding 没有真值，作者自己承认 reward hacking 是开放问题。
  - A-RSI 的答案由程序计算；1,000 道抽检题与独立求解器 1000/1000 一致。
  - Voyager 去掉“验证后才入库”，发现的物品少 73%。
- **为什么重要**：自我改进的上限取决于判对错的信号有多可靠。
- **Kaizen 怎么做**
  - 验证 agent 只看孪生的干预反馈：按提议整改后良率是否恢复，看不到执行 agent 的推理。
  - 产线标签只来自工程师关案。
  - 孪生标签权重 0.5，产线确认权重 1.0。
  - v0.6 的近邻练习、可靠度模型训练也只用这两种标签。

### 1.3 贝叶斯记忆与带条件的经验条目

- **文献**
  - TTSE 把经验写成“在 <条件> 下：<做法>”。
  - Bayesian-Agent 把每条经验当成假设，用 Beta 后验管理；默认 P < 0.45 且失败 ≥ 4 次停用，P ≥ 0.72 且 ≥ 3 次标为稳定。
  - ACE 的经验手册是带编号的条目加有用 / 有害计数，只做增量修改；它指出整段重写会导致“上下文坍塌”。
  - A-MEM 直接覆盖旧笔记、没有版本，审计上不可取。
- **为什么重要**：经验要能被验证、被推翻，还能说清楚在什么条件下有效。
- **Kaizen 怎么做**
  - 根因先验是 Dirichlet 计数。
  - 流程与教训条目保留条件和通过 / 失败次数，失败多于成功 2 次自动停用。
  - v0.6 的任务经验沿用 Bayesian-Agent 的阈值。
  - 所有更新都是增量修改，停用的条目留档。

### 1.4 课程 agent：按信息价值出题

- **文献**
  - Voyager 把课程换成随机出题，发现的物品少 93%。
  - R-Zero 的出题目标是让解题方成功率接近 50%（奖励 1 − 2|p̂ − ½|）。
  - **反例**：A-RSI 发现按固定配额随机抽题，比失败优先、难度阶梯都好（−0.82 到 −2.63 分）。原因是随机池保留了“写不完”的题，而这类题的终止奖励信号最强。
- **为什么重要**：出题决定了练什么，但“难题优先”并不总是对的。
- **Kaizen 怎么做**
  - 课程 agent 用知识梯度 × 证据模糊率估算“再练几道能涨多少”。
  - 校准批按信息价值分配症状，难度混合（易 : 中 : 难 = 2 : 4 : 4），不全选难题。
  - v0.6 的近邻练习是同一个课程 agent 针对单个案例出题。

### 1.5 产线变更与部分遗忘

- **文献**
  - TTSE 的出发点就是：环境一变（文件位置、数据格式、模板），旧经验就失效；失败后要能分清是做法错了还是对环境的认识错了。
  - SEAL 连续自编辑时出现灾难性遗忘，作者没有优化保留。
- **为什么重要**：工厂会换供应商、导入新机台。记忆跟不上，越有把握反而越容易错。
- **Kaizen 怎么做**
  - 产线变更同步到孪生时，受影响症状学到的份额只保留 20%。
  - 下一次 RSI 会话把这些症状的校准题比例提高到 4 倍，并允许它们更新先验。
  - 真实案例回放用同样的规则。

### 1.6 三套题集互不重叠

- **文献**
  - RSI-Opt 用种子 100/101 搜索，102/103 选择，200–202 报告。
  - Agnes 的 Train / Eval / Sealed 三份数据中，Sealed 对所有提议者不可见。
- **Kaizen 怎么做**
  - 测试集、验收门面板、练习题的种子段互不重叠。
  - v0.6 的 RRSI 进化用 search / select / report 三套孪生题，report 只在最后用一次。

## 2. v0.7：快脑小模型 + Harness 层

### 2.1 快脑是一个训练出来的小模型（Agnes Harness 的 System 1）

- **文献**
  - Agnes 的快脑（System 1）是一个专门训练的小决策模型，大模型做慢脑（System 2）；置信度低于阈值、任务第一步、上一步失败、连续执行多步之后，交还给慢脑。
  - 报告数字（封闭仿真）：单步 0.53 s 对 7.6 s；单次决策 $0.000091 对 $0.00247。
  - 排序网络的工业做法：Wide & Deep（宽部分记忆、深部分泛化）、DCN-v2（低秩交叉层显式学特征交互）、列表式 softmax 损失；概率用温度缩放校准。
  - 小规模表格数据上，GBDT（LightGBM / XGBoost 的 LambdaMART）常常比深度模型强（Grinsztajn et al. 2022）。
- **为什么重要**：v0.6 的“快脑”只是贝叶斯计数加 5 个权重；训练出来的组件只给可靠度、不碰排序，等于没把训练用在判断上。
- **Kaizen 怎么做**
  - **结构**：Wide & Deep & Cross。宽部分初始化为 RSIAgent 学到的贝叶斯证据权重，深部分一层隐层，交叉部分是 DCN-v2 低秩交叉层，再加根因 ID 嵌入和根因偏置层。未训练时完全等于贝叶斯排序。
  - **特征**：贝叶斯 5 个证据因子之外，再加贝叶斯乘积模型表达不了的结构信号，例如未达显著的机台信号 × 机台热点记忆、变点是否就在本工序、PM 后突变是否在本工序机台。刻意剔除会泄露答案的仿真伪迹。
  - **原始信号特征**：统计内核原来把良率二值化成“失效 / 不失效”再做 Fisher 检验，弱异常时大部分信息在这一步就丢了。新增的原始信号用连续指标，在整体变点之后的时间窗里逐工序、逐机台做 Welch t 检验，再加上变点前是否本来就差、变点前是否刚做过 PM。
    - 离线对照（同一 480 题测试集）：原特征 81.3% → 加原始信号 92.1%，困难题 71.2% → 88.8%，对数损失 0.49 → 0.23。
    - 工业模型对照（原特征上）：深度集成（TabM 思路）、列表上下文（PRM / SetRank 思路）、GBDT（LambdaMART 式）都在 81% 左右，说明瓶颈在信息量而不在模型结构；特征变丰富之后，交叉层让校准再好一点（ECE 0.021 → 0.014），命中率不变。
  - **实测**（同一 480 题 RSI 测试集）：贝叶斯 75.2%；Wide & Deep 81.9%；加交叉层和嵌入后 81.9%，对数损失 0.69 → 0.49，ECE 0.077 → 0.013。贝叶斯这一类模型的天花板（真实先验 + 在测试集上拟合权重）只有 74.6%。
  - 交叉层在原特征上没带来可测的提升（关键交互已经做成特征了）；加了原始信号之后命中率仍然不变，但概率校准更好。所以默认开启（秩 4），必要时交给 RSI-Opt：只有对数损失显著下降才改它的秩，不会因为“同样好、更省”就被去掉。
  - **没用 GBDT 的原因**：需要下载原生库；而且 GBDT 不方便做“只改偏置层的测试时训练”和“锚定上一版的连续训练”。
  - **裁决权**：通过晋升门才拿到；否则快脑退回贝叶斯。快脑的校准概率同时是路由依据和报告里的置信度。

### 2.2 A-RSI 用在快脑的训练上：何时更新、最后是否更新

- **文献**：A-RSI 只训练求解模型，标签由程序计算。
  - 训练分窗口，每个窗口固定步数，从上一次被接受的权重继续。
  - 换池规则：同一池至少 3 个窗口，且有学习信号的题数跌到 2 个窗口前的 85% 以下，或正确率比 2 个窗口前高 10 个点以上。
  - 健康门不过重试一次，再不过就停，回到上一个被接受的检查点。
  - 局限：没有留出集晋升门；没有置信度校准；模型预测自己会错哪些题，AUC 约 0.50。
- **Kaizen 怎么做**
  - **何时开窗**（事件触发）：
    - 没有窗口；
    - 新增 ≥ 20 条现场确认；
    - 孪生同步了产线变更；
    - 样本池饱和（A-RSI 的换池规则）；
    - 慢脑推翻快脑 ≥ 8 次（System 2 回流到 System 1）；
    - 产线命中率比留出集低 10 个百分点。
  - **训练数据**：课程 agent 按固定配额出题，孪生程序给标签；再加工程师确认的收据，其中最近 20% 不进训练、留给晋升门。
  - **健康门**（补全了 A-RSI 没有的检查）：
    - 参数有限且不爆炸；
    - 验证损失确实下降；
    - 参数确实变了；
    - 输出不塌缩；
    - 不过拟合；
    - 温度在 0.5~2.0；
    - 分症状不比贝叶斯差 0.25 以上。
  - **晋升门**（A-RSI 没有，这里补上）：
    - 每晋升一次换一块全新的留出集，避免可复用留出集问题；
    - 对数损失配对区间上界 ≤ 0；
    - 命中率下界 ≥ −2 个百分点；
    - ECE 不变差；
    - 对贝叶斯不退步；
    - 分症状护栏；
    - 保形覆盖 ≥ 87%；
    - 产线时间留出不比在用版本和贝叶斯差 5 个百分点以上。

### 2.3 RSI-Opt 用在快脑的训练上：内外两层

- **文献**：RSI-Opt 让 agent 在训练过程的决策点上做决定（内层），并跨 run 继承、进化训练策略（外层）；所有策略存档，父代采样 ∝ sigmoid(得分 − 中位数) / (1 + 子代数)。
  - 它的教训：没有验收门，训练任务上一路上涨（+10.48 → +14.33），留出任务第 1 代之后就不再提升。
- **Kaizen 怎么做**
  - **内层**：每个 epoch 末，控制器决定继续、学习率减半、回滚到最好的一轮或提前停止。
  - **外层**：进化训练策略，包括学习率、轮数、隐层宽度、嵌入维度、正则、出题配比和产线样本权重；DCN-v2 交叉层的秩默认 4，只有显著更好时才改。
    - 每个候选从贝叶斯初始化重新训练，公平比较；search 池训练，select 集验收，report 集只用一次确认。
    - 噪声带内只接受更便宜或更简单的。
  - **何时跑**：事件触发——还没有策略，或连续 2 个训练窗口没通过。
  - **训练知识库**（RSI-Opt 的跨 run 知识）：
    - 事实：训练池里各症状的首位根因、模型偏弱的分组；
    - 做法：控制器规则和出题配比是否有效。
    - 事实被新窗口推翻（产线变了）就停用，并让该症状下个窗口配额加倍；做法失败追责，停用留档，控制器和策略提议不再用它。

### 2.4 TTSE 用在 RSIAgent 的三个 agent 上

- **文献**
  - TTSE 是不改参数、在测试时靠经验进化的 agent 框架：事实 / 做法两轨，失败追责到具体条目，被追责的停用但留档，拿不准时记为做法。
  - 结果：ALFWorld 98.51%（GLM-5）；GDPevo 上双轨 0.2616，只用 TIP 0.2380，只用 FACT 0.1918。
  - 局限：规则没有留出集验证，归咎也可能错。
- **为什么用在三个 agent 上**：RSIAgent 的课程 / 执行 / 验证 agent 本来就不训练参数，正是 TTSE 的适用对象。v0.6 把 TTSE 用在 harness 经验上，v0.7 第一版又借它的结构管模型训练，都不贴切。
- **Kaizen 怎么做**
  - **事实轨**：验证 agent 确认过的“机台 ↔ 根因”，满 3 次确认才生效；按它整改却没恢复时追责。
  - **做法轨**：
    - 执行 agent 的“同条件下先查哪个根因”“哪个整改无效”；
    - 课程 agent 的“失败后针对性加练是否有用”。
  - **测试时使用**：
    - 执行 agent 作答时检索稳定的做法条目（P ≥ 0.8、排在前三、后验不低于首位一半）先试；
    - 课程 agent 在加练条目停用的症状上不再加练。
  - **追责与停用**：失败追责到当时实际用到的条目；P < 0.45 且失败 ≥ 4 次停用，留档可查。
  - **补上的验证**：任何条目的成败只由验证 agent 的干预反馈判定，补上了 TTSE 缺的验证。

### 2.5 慢脑：双层递归的内层（Harness²）与两个挑战者

- **文献**
  - Harness² 的内层是提议通用 / 领域候选 → 在同一任务上探测、做行为对比 → 合成有证据支持的改动；外层把“什么条件下哪种改动有效”写进改进库，下一个任务仍从干净的基础 harness 出发。
    - 结果：WorkBuddy-Bench 64.2 → 75.7；去掉改进库降 3.1 分。
    - 局限：没有正确性信号。
  - Agnes Sys1 的 TTT 是逐请求出可验证的辅助题、只改少量参数、对基线锚定、用完即弃、变差就回退（Sun et al. 2020），报告里没有实验结果。
- **Kaizen 怎么做**
  - **出题**：课程 agent 针对本案出 36 道近邻孪生题，其中 12 道是探测题。
  - **两个挑战者，各管一种错**：
    - 近邻训练：24 道近邻题由执行 agent 作答、验证 agent 判定，只更新一份临时贝叶斯记忆；快脑模型冻结参数，读入临时记忆重排，用完即弃。管“记忆过时了”（产线变了）。
    - 贝叶斯意见：结构完全不同、零成本，管模型自己外推出错。
  - **为什么只调模型偏置不行**：v0.7 早期另有一个“只调快脑根因偏置层”的挑战者（照 Agnes 的“只改少量参数”）。实测：
    - 演示历史 48 次慢脑里只赢过快脑 1 次；
    - 孪生压力题 144 道探测题上，比快脑少答对 11 道；和近邻练习叠加时把同一个变化算了两次（126 → 106）。
    - 合并后，“临时记忆 + 冻结的快脑模型”在两组压力题上都最好：探测命中 126 / 144 与 116 / 144，原来的贝叶斯近邻练习是 121 与 100。
    - 结论：测试时该训练的是模型读的记忆，而不是模型的权重。
  - **裁决**：同一批探测题上比命中，挑战者必须多答对 ≥ max(1, ⌈改判门槛 × 12⌉) 道才改判；打平用快脑。有 Key 时，大模型调查员在沙箱里核查数据（支持 ×1.3、反驳 ×0.7）。
  - **外层**：
    - 慢脑做完，按探测对比更新改进经验库（没有行为差异就不新增条目）；
    - 关案后按现场结果更新“快脑可信”与“改判是否正确”；
    - 推翻关案时撤回。

### 2.6 RRSI 用在 harness 上：进化基础 harness

- **文献**
  - **提议端**：改动数退火；记录每次改动的组件、假设、实测效果；停滞时尝试没改过的组件。
  - **选择端**：拒绝夹带基准专属信息的改动；稳定性下限；改进在噪声带内只有降低成本才接受；剪掉长期无贡献的组件。
  - **结果**：进化集最多 +6.0，分布外 +4.3，policy token 少 30%。
  - Agnes 的字典序目标与上线观察期。
- **Kaizen 怎么做**
  - **进化对象**：基础 harness 的组件配置（路由门槛、抽查间隔、两个挑战者的开关与题量、锚定、改判门槛、是否按改进库调整、大模型调查员何时调用），以及**条件规则**。
    - 条件规则从改进经验库提议，例如“若［某症状 · 证据模糊］→ 近邻训练关”。
    - 防泄漏审查：只能以可观察的条件字段为条件，来源必须是改进库，search 和 select 集上都要有 ≥ 3 道支持题。
  - **何时跑**（参照 A-RSI，事件触发）：
    - 改进库新出现 ≥ 3 条稳定或停用的经验；
    - 产线确认的快脑错误 ≥ 3 次且 ≥ 15%；
    - 新快脑模型上线；
    - 孪生同步了产线变更；
    - 慢脑赢过快脑的比例跌到两次前的 85% 以下。
    - 连续两次没接受任何候选就退避，只响应强信号。
  - **是否上线**（RRSI 自己的门，比 v0.6 严）：
    - **选择门**：白名单与防泄漏审查 → search 初筛 → select 验收（按本次已评估的候选数做 Bonferroni 校正）；
    - **上线门**：每次全新的 report 题，平均差 ≥ 0 且下界 ≥ −2 个百分点，成本变高必须显著更好，再加产线回放；
    - **观察期**：错误率 Wilson 区间下界同时高于上一版和路由承诺的错误率时回滚。
  - **正则**：改动预算退火 3 → 2 → 1 + 复杂度感知 + 剪枝。

### 2.7 三层三套门

| 层 | 门 | v0.6 的问题 | v0.7 的做法 |
|---|---|---|---|
| RSIAgent | 验收门 | 120 题比点估计；同一块面板一直用；只看平均 | 240 题；配对 bootstrap；分症状护栏；每采纳一次换一块面板 |
| 快脑模型 | 健康门 | （新） | 有限、不爆炸、学到了、变了、不塌缩、不过拟合、温度正常、分症状不比贝叶斯差 |
| 快脑模型 | 晋升门 | 固定留出集、只看孪生、只看平均、不管覆盖率 | 轮换留出集 + 产线时间留出 + 分症状护栏 + 保形覆盖 |
| harness | 选择门 + 上线门 + 观察期 | 多重比较没校正；report 集反复用；上线只要求不退步；观察期是固定阈值 | Bonferroni；每次全新 report 题 + 产线回放；平均差 ≥ 0；统计检验式观察期 |

## 3. 五大路线在 Kaizen 的取舍

| 路线 | 代表工作 | Kaizen 的结论 |
|---|---|---|
| ① 模型权重训练 | Self-Rewarding、SPIN、Quiet-STaR、SEAL | v0.7 起训练一个小排序模型做快脑（不训练大模型）。借鉴：SPIN 的固定真值锚点（工程师确认的根因永久保留）；SEAL 的“更新后的表现即奖励”，即晋升门；永远不用模型自评当标签 |
| ② 提示与框架进化 | STOP、ADAS、TextGrad、DSPy | 只影响可选的大模型层。借鉴：TextGrad 的验证集准入；ADAS 用多次运行加 bootstrap 区间做决定 |
| ③ 记忆与技能库 | Voyager、Reflexion、ACE、MemEvolve | **最适合**，就是 Kaizen 的主线：条件化条目、增量合并、验证后入库；MemEvolve 式的记忆超参数搜索对应 v0.6 的 RRSI 策略进化 |
| ④ 自改代码 | Gödel Agent、DGM、AlphaEvolve、ShinkaEvolve | 产线运行时不让 agent 改自己的代码（变更管控）。借鉴存档、父代采样、先便宜后贵的分级评估 |
| ⑤ 多智能体协同进化 | R-Zero、EvoAgentX、AI Scientist | 借鉴 R-Zero 的出题目标（成功率约 50%）和它的教训：永远不把自己的高置信结论当标签 |

## 4. 已知局限

- 所有数字都来自模拟数据与数字孪生。孪生没有用本厂数据校准之前，学到的是孪生而不是产线。
- 快脑模型的训练标签在孪生里由程序给出；孪生没有用本厂数据校准之前，模型学到的“现在哪个根因常见”是孪生的。产线时间留出与产线回放是为了尽早发现这种差距。
- 测试时训练与近邻练习在平常场景基本不改判，它们的价值集中在产线变更之后、下一个训练窗口之前。
- 三套门都偏严，多数候选会被拒（RRSI 原文 30 轮中 10 轮被接受）。这是有意的：工业场景里“不上线”比“上线一个靠运气挑出来的版本”便宜。
- 交叉层默认开启：它在命中率上没有可测的提升，换来的是概率校准更好（ECE 0.021 → 0.014）和约 1.6 倍的参数量；要改它，RSI-Opt 必须拿出对数损失显著下降的证据。
- 首次生成演示数据较慢（历史回放里要训练快脑、跑慢脑和 RRSI）；服务器仍然 2 秒内可用，数据在后台生成。
